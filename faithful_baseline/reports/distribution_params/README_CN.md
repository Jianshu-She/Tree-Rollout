# Flat Rollout 树结构的分布参数拟合报告

> 从 400 道 MATH500 题目 × 4 个 RL 训练阶段（共 1600 棵树，每题 128 条 rollout）中拟合得到。
> 使用 difflib 文本相似度（阈值 0.3）做 syntactic clustering，256 token 为一个 chunk。

---

## 1. 建模决策：D0 用负二项分布，D1+ 用泊松分布

![建模决策](hero_distribution_choice.png)

**这张图回答的核心问题：branching factor 应该用什么分布来建模？**

- **(a) 离散度比（Var/Mean）随深度的变化**：红色阴影区域表示"过度离散"（var/mean > 1），此时泊松分布不适用，需要负二项分布。绿色区域表示"欠离散"（var/mean < 1），泊松分布足够。可以看到 D0（深度0）的离散度在 3~18 倍之间，远超泊松假设的 var=mean；而 D3 以后的 var/mean < 1，泊松分布成立。

- **(b) D0 的负二项分布参数**：紫色柱是 r（形状参数，控制尾部厚度，越小尾越重），黄色柱是 p×10（成功概率），深色柱是 E[bf]/5（均值缩放）。随着训练推进，均值从 26 降到 4，但 r 从 1.5 增到 1.9（尾部变轻）。

- **(c) D1+ 的泊松 λ 值**：训练后模型在 D1 有较高的 λ（3.7~4.6），但 D3 以后迅速衰减到 ~1（不再分叉）。

| 深度 | 分支因子模型 | 原因 |
|------|------------|------|
| D0 | **负二项分布 NegBin(r, p)** | var/mean = 3~18 倍，严重过度离散 |
| D1+ | **泊松分布 Poisson(λ)** | var/mean ≤ 1，无过度离散 |

节点准确率在所有深度：**Beta(α, β)** — U 型分布（α, β < 1）。

## 2. D0 的负二项分布 vs 泊松分布

![D0 NegBin vs Poisson](negbin_vs_poisson_d0.png)

**这张图展示：为什么 D0 不能用泊松分布？**

每个子图对应一个训练阶段。彩色填充曲线是负二项分布的 PMF，黑色虚线是泊松分布的 PMF。

- **Base model (step 0)**：泊松分布（λ=26）预测的峰值在 25 附近，但实际数据有大量 bf=1~5 的小值和一些 bf=50+ 的极端值。负二项分布（r=1.51, p=0.055）的重尾能很好地拟合这种"要么很少分支，要么非常多分支"的模式。

- **训练后模型（step 40~120）**：均值降到 4~6，但仍然有明显的右偏重尾。泊松分布过于对称，NegBin 更好。

---

## 3. D0 的节点准确率：Beta 分布

![D0 Beta 分布](beta_d0_illustration.png)

**这张图展示：树的根节点准确率是什么分布？**

每个子图是一个训练阶段的 Beta 分布概率密度函数。黑色竖虚线是均值 E[acc] = α/(α+β)。

- **关键特征：U 型分布（α, β 都 < 1）**。这意味着节点要么几乎全对（acc ≈ 1），要么几乎全错（acc ≈ 0），很少有"半对半错"的节点。这说明 syntactic clustering 在 D0 就已经很好地分离了正确和错误的推理路径。

- **训练效果**：随着训练推进，分布从左偏（step_0, E=0.39, 大部分节点偏错）变成右偏（step_120, E=0.72, 大部分节点偏对）。

---

## 4. RL 训练如何改变树结构分布

![RL 训练演化](rl_training_evolution.png)

**这张图展示：训练过程中三个关键指标的变化趋势。**

- **(a) D0 平均分支因子**：从 26.0（base model）急剧下降到 5.7（step 40），然后缓慢下降到 4.0（step 120）。说明 RL 训练让模型的推理路径从"非常发散"收敛到"少数几条主要策略"。最大的变化发生在训练初期（step 0→40）。

- **(b) D0 平均节点准确率**：从 0.39 上升到 0.72。模型学会了更多正确的推理方式。

- **(c) D0 NegBin r 参数**：从 1.51 先降到 1.21（step 40，尾更重），再升到 ~2.0（step 80-120，尾变轻）。这说明训练初期分支数的方差反而增大（有些题模型学会了但有些没有），后期才稳定下来。

## 5. Stage × Depth 参数热力图

![参数热力图](parameter_heatmaps.png)

**这张图是所有参数的全景视图。**

- **左图：泊松 λ（分支因子）**。深色 = 高分支。可以清楚看到 step_0 的 D0 格子最深（λ=26），而其他所有格子都是浅黄色（λ ≈ 1~5）。这验证了"分支主要发生在浅层"的结论。

- **右图：Beta 均值（节点准确率）**。绿色 = 高准确率，红色 = 低准确率。从上到下（base → trained），绿色越来越多。从左到右（D0 → D10），准确率递减——因为深层节点的 rollout 更少，估计更嘈杂。

## 6. 树结构统计曲线 W(d), B(d), S(d), P(d)

![WBSP 曲线](tree_curves_WBSP.png)

**这张图是树结构的四个关键统计量随深度变化的曲线。**

- **W(d) 宽度**：深度 d 处的平均节点数。Base model 在 D3 达到峰值（~48 个节点），训练后模型在 D3-4 达到峰值（~30-34）然后缓慢下降。

- **B(d) 分支因子**：深度 d 处的平均分支数。Base model 在 D0 极高（26），D1 后迅速降到 ~1。训练后模型在 D0-D1 有 4~5 的分支，D3 后也降到 ~1。

- **S(d) 存活 rollout 数**：在深度 d 处仍然"存活"的 rollout 平均数量。128 条 rollout 开始，base model 到 D3 就只剩 ~80 条了（很多 rollout 文本短，提前结束）。训练后模型的 rollout 存活更久。

- **P(d) 节点纯度**：每个节点中多数类（正确/错误）的比例。所有阶段在 D4-5 后都达到 ~1.0 的纯度，说明树在浅层就完成了正确/错误路径的分离。

## 7. 拟合质量检验

### 泊松 vs 负二项拟合

![拟合质量 - 分支因子](poisson_vs_negbin_histograms.png)

**这张图展示：Poisson 和 NegBin 对实际 branching factor 直方图的拟合程度。**

每行是一个深度（D0, D1, D2, D4），每列是一个训练阶段。彩色柱状图是真实数据，黑色虚线是泊松拟合，红色实线是负二项拟合。

- **D0 行**：泊松分布明显拟合不好（峰值位置和尾部都不对），负二项分布能很好地捕捉重尾特征。
- **D2, D4 行**：数据高度集中在 1（大部分节点只有 1 个 child），泊松分布足够。

### Beta 拟合

![拟合质量 - 准确率](beta_fit_histograms.png)

**这张图展示：Beta 分布对节点准确率直方图的拟合程度。**

- 所有深度和阶段的准确率分布都呈现 U 型（两端高、中间低），Beta 分布（α, β < 1）能很好地拟合。
- 训练后模型的右峰（acc ≈ 1）更高，说明更多节点是正确的。

## 9. 对 Poisson-MCTS 的启示

基于以上分析，我们提出的 Poisson-MCTS 应该：

1. **D0 层**：从 NegBin(r, p) 采样分支数，参数随训练阶段变化（base: r=1.5, p=0.055; trained: r=1.9, p=0.32）
2. **D1+ 层**：从 Poisson(λ_d) 采样分支数，λ 随深度快速衰减到 ~1
3. **节点奖励先验**：用 Beta(α, β) 初始化，α, β < 1（U 型先验）
4. **关键区别于 DeepSearch**：我们的分支数是**随问题和模型自适应的**（通过分布的方差体现），而不是固定的

## 实验设置

- **模型**: Qwen2.5-Math-7B-Instruct, DAPO RL 训练
- **检查点**: step 0 (base), 40, 80, 120
- **数据集**: MATH500, 前 400 题 (训练集), 后 100 题 (验证集)
- **Rollout**: 每题 128 条, vLLM, tensor_parallel_size=2
- **分块**: 256 token 一个 chunk (Qwen tokenizer)
- **聚类**: Syntactic (difflib SequenceMatcher, 阈值=0.3)
- **建树**: 从 flat rollout 后处理构建，终止的 rollout 保留为叶子节点
